# Ariele Correia — landing page

Landing page estática para a psicóloga infantil Ariele Correia, com foco em contato pelo WhatsApp.

## Contato

O número em `script.js` é **fictício e temporário** (`5511999999999`), conforme solicitado para a publicação inicial. Substitua `whatsappNumber` pelo número real no formato `55 + DDD + número`.

## Publicação

Os arquivos podem ser servidos diretamente por qualquer hospedagem estática. A página não exige build nem dependências.
